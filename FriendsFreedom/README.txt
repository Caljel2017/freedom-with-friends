# Friends Freedom — drop-in mod

Title ID: 01006F8002326000

Put this whole folder under your emulator's mods/load path for ACNH.

## Folders

- `exefs/` — code patches (`.pchtxt` for Ryujinx/Yuzu; `.ips` also used on Atmosphere)
- `romfs/` — replaced game files (EventFlow cutscene skips, etc.)
- `cheats/` — optional Atmosphere/Ryujinx cheat texts named `<BUILDID>.txt`

## Enable

1. Install via `..\install\Install-Yuzu.ps1` or `Install-Ryujinx.ps1`
2. Confirm the mod is enabled for Animal Crossing: New Horizons
3. Every multiplayer client must use the same game version and the same mod files

Until real patches are added under `exefs/` / `romfs/`, this folder is a ready shell only.
